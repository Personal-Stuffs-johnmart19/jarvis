# Integrated Jarvis workspace

The adapted Terax frontend is compiled into the main Jarvis desktop. Chat, voice commands, Files & Tools and settings share the agent runtime, selected providers and capability catalogue. There is no external Terax process in the workspace UI.

Use the canonical guides for [architecture](../../../docs/ARCHITECTURE.md), [development and checks](../../../docs/DEVELOPMENT.md), [files and editor context](../../../docs/FILES.md), [provider setup](../../../docs/INTEGRATIONS.md) and [localization](../../../docs/LOCALIZATION.md). Keep operating instructions there rather than maintaining a second feature checklist here.

Upstream provenance is recorded in `SOURCE.json`. Preserve this directory's `LICENSE`, the native workbench license and the [adaptation notice](../../../third_party/terax/NOTICE.md).
